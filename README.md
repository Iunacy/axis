# AXIS

I’m building AXIS, a chess analysis and personalized improvement platform, to turn game review into focused practice.

I can import completed games from Chess.com, Lichess, or PGN and open them for automatic Stockfish analysis in my browser. Reviews save progressively, resume after interruptions, and load from cache on return. I can navigate moves and legal variations, explore positions, review evidence-based move classifications, and practice corrections from my games. Lessons, mating-pattern exercises, and master-game studies support further learning. My games, settings, and training history stay on this device.

[Open AXIS](https://axls.vercel.app/)
